Principais fundamentos do vôlei

Por: Andressa Vitória

O vôlei é um esporte praticado por duas equipes, com seis jogadores de cada lado. Para jogar bem, é importante conhecer e praticar seus principais fundamentos.

Manchete

A manchete é utilizada principalmente para receber saques e defender ataques. Ela é feita com os braços unidos e os antebraços formando uma superfície para direcionar a bola.

Saque

O saque é o fundamento que inicia a jogada. O jogador deve lançar a bola e golpeá-la para o outro lado da quadra.

Toque

O toque é usado para controlar e levantar a bola, sendo muito importante para preparar uma jogada de ataque.

Cortada

A cortada é um dos principais movimentos de ataque. O jogador salta e golpeia a bola com força para tentar marcar o ponto.
